## 🌸 Sobre mí

Soy **estudiante de informática** cursando una doble titulación en **Desarrollo de Aplicaciones Multiplataforma (DAM)** y **Desarrollo de Aplicaciones Web (DAW)**. Me centro en el **backend** y el **desarrollo web full-stack**, con un interés creciente en **bases de datos, análisis de datos** y, más adelante, **ciberseguridad**.

Me importan el código limpio, las bases de datos bien diseñadas y las interfaces que sean funcionales *y* bonitas de ver — normalmente rosas. 🩷 Ahora mismo busco **prácticas FCT** para el curso 2026/2027.
